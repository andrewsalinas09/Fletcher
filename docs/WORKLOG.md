## 2026-08-23 (evening) — Q-24 ships: the history inspector

- **Did:** Built the inspector end-to-end in one pass (fresh session, planned from the handoff docs). **Rust:** `chain_curves` (batched responses + matched preamps for arbitrary chains — no command could answer for a non-live chain before), `preview_chain` (level-matched fletcher.txt-only audition: no preset write, no abSide reset, refused mid-ABX), `preset_create_from_chain` (auto-suffixed promote), and the ABX engine generalized — `abx_start` optionally takes two chains + names (classic preset-vs-flat unchanged), auditions go through `activate_chain` so level matching between any two chains is free, a response-difference guard replaces the filter-count check, and results now carry both chains + `referenceDb` as provenance (labeled replay of node sessions works from the record). Extracted `chain_of` as the shared validate/clamp adapter. **UI:** right-side inspector inside the shared `HistoryTree` (both windows — snapshots now ride `hist-sync`; pop-out mutations/audio route via `hist-cmd`, curve reads invoke directly): rename/note/pin (persisted, tolerant v1 format), "vs: parent ▾" chip with pick-mode, parametric diff (greedy kind+nearest-log-Fc pairing; leftover pairs at ~same Fc read as type changes), the level-matched difference curve with boost/cut shading + faint context curves + its own auto/±3/±6/±12 scale chips, multi-node compare (Ctrl+click; overlaid color-coded diff curves vs the shared base, legend rows with mean |Δ|), listen previews with restore-on-unmount/-on-move/-on-popout-destroy (TB-25), node-vs-node blind test surfacing the main window, promote + copy-as-APO (formatter unified with filter Ctrl+C). Edge thickness on the canvas = mean |audible diff| per edge. Click semantics per user: plain click keeps jump+inspect, Alt+click inspects silently, Ctrl+click compares (matches strip convention). TB-25/TB-26 filed; Q-17 closed; Q-24 marked shipped.
- **Did (live passes, same session):** Two taste passes with the user on the running app: all diff headers/mean-|Δ|/preamp readouts cut (level matching makes numbers dead weight), base picker became a direct pick-mode chip, previews became a HEAR #12|#11 segmented toggle (A/B idiom; button trios read as mess), "promote"→"save as preset", jump button dropped (clicking the node IS jump), diff scale ±3/±6/±12/±18/±30, Esc deselects filters on the EQ tab, **concrete node ids everywhere** (blind test #12 vs #11; ids drawn inside the circles, long labels truncated with full name on hover), undo/redo move the inspector selection (they're literally clicks on the graph). **The difference graph became the second pop-out** (⇱; main resolves the last-touched compare against the live tree — default current-vs-parent continuously shows "what did my last gesture change" while sculpting). **Drag-graft** (user idea): drag any node onto any other → its exact sound lands as ONE clean step ("N edits in one"), non-destructive squash, becomes current; works from the pop-out via hist-cmd.
- **Learned:** The backend never modeled history — trees are opaque JSON to Rust, so the whole inspector rides on chains-as-arguments commands. `activate_chain` was already the perfect preview/ABX primitive, just unexposed. **Platform law #2 (bit twice):** Tauri capabilities are per-window-label; an unlisted label renders with silently dead IPC — fixed as a class with `"windows": ["*"]`. **Dev law (took two rounds to name right):** vite fast-refresh never re-runs `[]`-effects, so long-lived listeners capture STALE closures — the popout→main command bus ran old code (first missing the graft case entirely, then showing a removed notice) while main-window paths ran current code. Class fix: trampoline refs (`busRef`/`keyRef`) — the registered callback is permanent, the ref body is refreshed every render. Every future long-lived listener follows this pattern. New repo rule #10: every feature is traced through the satellite path before it's called done. Verified end of session: main + both pop-outs all working (drag-graft from pop-out confirmed by user after fresh start); cargo test (27), clippy, fmt, tsc clean.
- **Did (later, same session):** **Settings v1 shipped** from the approved artboard: filter ordering (freq/importance/file — display-only strip sort), the **level-matching honesty switch** (off = clip-safety only; A/B bar shows "unmatched — louder side wins", trial room warns, `levelMatched` recorded in every session's provenance; refused mid-ABX), reference loudness as an editable value (calibration flow arrives with the generator, Q-16), Start with Windows (tauri-plugin-autostart), A/B hotkey display, Standard/Advanced mode wired to the Fingerprints tab (grey-don't-hide per ADR-0002, with the artboard's demo box), APO detection status.
