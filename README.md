# Fletcher

A modern, open-source frontend for [Equalizer APO](https://sourceforge.net/projects/equalizerapo/) — system-wide parametric EQ for Windows that is genuinely pleasant to use.

The feature that makes it different: **honest listening tests**. Blind ABX comparison of any two EQ configurations — level-matched by loudness so "louder sounds better" can't cheat, with real statistics (was that 14/16 luck, or can you actually hear it?). Applies to whatever you're playing system-wide, or to an imported track with seamless in-app switching.

Named for the [Fletcher–Munson equal-loudness curves](https://en.wikipedia.org/wiki/Equal-loudness_contour).
